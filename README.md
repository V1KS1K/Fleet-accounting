# Система учета общественного транспорта

Консольное приложение для поиска информации о транспорте, координации и управления маршрутами операторами движенияпше.

## Возможности
- просмотр списка маршрутов и остановок.
- вывод времени прибытия автобуса к остановке.
- проверка статуса автобуса.
- поиск маршрута по названию.
- сохранение и загрузка данных маршрутов из JSON-файлов.
- защита от некорректного ввода пользователя.

## Предметная область и сущности
Основными объектами предметной области являются:
- маршрут.
- расписание прибытия.
- трекер активности.

## Структура проекта
- `main.py` — точка запуска, основное меню и взаимодействие с пользователем;
- `buses.py` — функции работы с маршрутами и расписанием;
- `storage.py` — логика сохранения и загрузки данных;[cite: 2]
- `utils.py` — вспомогательные функции (безопасный ввод чисел);[cite: 2]
- `data/` — каталог с JSON-файлами данных;[cite: 2]
- `tests/` — автоматизированные тесты;[cite: 2]
- `requirements.txt` — список зависимостей проекта.[cite: 2]
