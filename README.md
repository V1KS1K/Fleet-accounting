# Система учета общественного транспорта

Консольное приложение для поиска информации о транспорте, координации и управления маршрутами операторами движения.

## Возможности
- просмотр списка автобусов, их маршрутов и остановок;
- вывод времени прибытия автобуса к начальной остановке;
- проверка статуса автобуса (в пути или в автопарке);
- поиск нужного автобуса по номеру маршрута
- сохранение и загрузка данных из взаимосвязанных JSON-файлов с восстановлением объектных связей
- защита от некорректного ввода пользователя.

## Предметная область и сущности
Приложение построено на объектно-ориентированной модели. Основными сущностями являются
- `Stop` (Остановка) — базовая сущность инфраструктуры
- `Route` (Маршрут) — содержит внутри себя список объектов остановок
- `Driver` (Водитель) — сотрудник, управляющий транспортным средством
- `Bus` (Автобус) — центральный объект, который ссылается на назначенный маршрут (`Route`) и водителя (`Driver`)

## Структура проекта
- `main.py` — точка запуска, основное меню и взаимодействие с пользователем
- `buses.py` — классы предметной области (`Stop`, `Route`, `Driver`, `Bus`) и функции поиска
- `storage.py` — логика сохранения и загрузки данных, сборка связей между объектами из JSON
- `utils.py` — вспомогательные функции (безопасный ввод чисел)
- `data/` — каталог с разделенными JSON-файлами данных
- `tests/` — автоматизированные тесты для проверки методов классов и логики приложения
