# Система учета общественного транспорта

## Назначение
Приложение помогающие в поиске информации о транспорте.
## Целевая аудитория
Операторы движения
## Предметная область
Координация и управление транспортом. 
## Основные сущности
- трекер активности
- расписание прибытия
- маршрут
## Основные функции
- Просмотр списка остоновок
- Просмотр время прибытия автобуса к остановке
- Вывод номера маршрута автобуса
- Проверка в пути ли автобус
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
