# Система учета общественного транспорта

## Назначение
Приложение помогающие в поиске информации о транспорте.
## Целевая аудитория
Операторы движения
## Предметная область
Координация и управление транспортом. 
## Основные сущности
- Bus
## Основные функции
- транспорт
- остановка
- расписание
- маршрут
## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
